Estrutura de seleção switch

A instrução switch avalia uma expressão e compara seu resultado com os valores definidos em cada case. Quando encontra uma correspondência, executa as instruções associadas àquele caso.

Quando utilizar

Essa estrutura é utilizada quando um mesmo valor precisa ser comparado com várias opções possíveis. O break encerra a execução do caso encontrado, enquanto o default trata valores que não correspondem a nenhum dos casos definidos.

Sintaxe básica


                switch (expressao) {
                    case valor1:
                        // Executado quando a expressão for igual ao valor1
                        break;

                    case valor2:
                        // Executado quando a expressão for igual ao valor2
                        break;

                    default:
                        // Executado quando nenhum caso corresponder
                }

Exemplo


                const opcao = 2;

                switch (opcao) {
                    case 1:
                        console.log("Cadastrar");
                        break;

                    case 2:
                        console.log("Consultar");
                        break;

                    default:
                        console.log("Opção inválida");
                }

Referência: MDN Web Docs — switch

Atividade prática

Identificação do dia da semana

Desenvolva uma aplicação que leia um número inteiro de 1 a 7 informado pelo usuário. O programa deverá utilizar a estrutura switch para apresentar o dia da semana correspondente, considerando 1 como domingo, 2 como segunda-feira e assim sucessivamente até 7, que representa sábado. O preenchimento do campo deve ser obrigatório e valores fora desse intervalo deverão ser informados como inválidos.

Como acompanhar a saída

Esta atividade apresenta a resposta em uma caixa visual para que seja possível acompanhar a saída sem abrir as ferramentas de desenvolvimento do navegador. A mesma mensagem também é enviada ao console real por meio de console.log().

No Google Chrome ou Microsoft Edge, pressione Ctrl + Shift + J para abrir diretamente o console. Também é possível pressionar F12 e selecionar a aba Console. No macOS, utilize Command + Option + J.

Consulte também as instruções do Chrome DevTools .
