Estrutura condicional if...else

A instrução if...else avalia uma condição. Quando essa condição é verdadeira, o bloco associado ao if é executado. Quando é falsa, o bloco do else pode ser executado.

Quando utilizar

Essa estrutura é utilizada quando o programa precisa decidir entre caminhos diferentes de execução com base no resultado de uma condição.

Sintaxe básica


                if (condicao) {
                    // Executado quando a condição for verdadeira
                } else {
                    // Executado quando a condição for falsa
                }

Exemplo


                const estoque = 3;

                if (estoque > 0) {
                    console.log("Produto disponível");
                } else {
                    console.log("Produto indisponível");
                }

Referência: MDN Web Docs — if...else

Atividade prática

Verificação de maioridade

Desenvolva uma aplicação que leia a idade informada pelo usuário em um campo de formulário. O preenchimento do campo deve ser obrigatório. Após receber o valor, o programa deverá informar se a pessoa é maior de idade, considerando maior de idade quem possui 18 anos ou mais. Caso tenha menos de 18 anos, deverá informar que a pessoa é menor de idade.
