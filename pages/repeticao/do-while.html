Estrutura de repetição do...while

A instrução do...while executa um bloco de instruções e, somente depois, verifica se a condição da repetição permanece verdadeira.

Quando utilizar

Essa estrutura é indicada quando o bloco precisa ser executado pelo menos uma vez antes que a condição seja verificada. Depois da primeira execução, a condição determina se haverá uma nova repetição.

Essa é a principal diferença em relação ao while, que verifica a condição antes de executar seu bloco.

Sintaxe básica


                do {
                    // Instruções executadas em cada repetição

                    // Atualização da variável utilizada na condição
                } while (condicao);

Na estrutura do...while, o ponto e vírgula depois da condição faz parte da sintaxe.

Exemplo


                let contagem = 3;

                do {
                    console.log("Contagem: " + contagem);

                    contagem--;
                } while (contagem > 0);

Nesse exemplo, o bloco apresenta os números 3, 2 e 1. Depois que contagem passa a valer 0, a condição se torna falsa e a repetição termina.

Referência: MDN Web Docs — do...while

Atividade prática

Somatório de números

Desenvolva uma aplicação que utilize a estrutura de repetição do...while para solicitar números ao usuário por meio de prompt(). Depois de cada número, o programa deverá acrescentá-lo ao somatório e perguntar se o usuário deseja continuar. Para encerrar a repetição, o usuário deverá digitar 0 na solicitação de continuidade. Ao final, o resultado da soma deverá ser apresentado no console.

Como os valores serão solicitados por caixas de diálogo prompt(), o formulário terá apenas o botão Enviar e não possuirá campos de entrada.

Como acompanhar a saída

A atividade apresentará cada número informado e o resultado final da soma em uma caixa visual dentro da página. As mesmas informações também serão enviadas ao console real do navegador por meio de console.log().

No Google Chrome ou Microsoft Edge, pressione Ctrl + Shift + J para abrir diretamente o console. Também é possível pressionar F12 e selecionar a aba Console. No macOS, utilize Command + Option + J.

Consulte também as instruções do Chrome DevTools .
