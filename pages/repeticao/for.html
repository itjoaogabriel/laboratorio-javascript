Estrutura de repetição for

A instrução for cria uma repetição controlada por três expressões: inicialização, condição e atualização. Enquanto a condição permanecer verdadeira, o bloco de instruções será executado novamente.

Quando utilizar

Essa estrutura é indicada principalmente quando sabemos quantas vezes uma ação precisa ser repetida ou quando queremos controlar a repetição utilizando um contador.

Sintaxe básica


                for (inicializacao; condicao; atualizacao) {
                    // Instruções executadas em cada repetição
                }

As três partes possuem responsabilidades diferentes:

  • inicializacao: cria ou define o valor inicial do contador.
  • condicao: determina se a repetição continuará.
  • atualizacao: altera o contador depois de cada repetição.

Exemplo


                for (let tentativa = 1; tentativa <= 3; tentativa++) {
                    console.log("Tentativa número " + tentativa);
                }

Referência: MDN Web Docs — for

Atividade prática

Contagem de 1 a 10

Desenvolva uma aplicação que utilize a estrutura de repetição for para imprimir no console os números inteiros compreendidos entre 1 e 10. A cada repetição, o programa deverá apresentar uma mensagem informando o número da passagem e o valor atual do contador.

Como a atividade não solicita dados ao usuário, o formulário terá apenas o botão Enviar e não precisará validar campos obrigatórios.

Como acompanhar a saída

A atividade apresentará as dez mensagens em uma caixa visual para que a sequência possa ser acompanhada diretamente na página. As mesmas mensagens também serão enviadas ao console real do navegador por meio de console.log().

No Google Chrome ou Microsoft Edge, pressione Ctrl + Shift + J para abrir diretamente o console. Também é possível pressionar F12 e selecionar a aba Console. No macOS, utilize Command + Option + J.

Consulte também as instruções do Chrome DevTools .
