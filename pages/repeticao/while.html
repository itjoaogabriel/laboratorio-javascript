Estrutura de repetição while

A instrução while executa repetidamente um bloco de instruções enquanto uma condição permanecer verdadeira. Essa condição é verificada antes de cada repetição.

Quando utilizar

Essa estrutura é indicada quando a continuidade da repetição depende de uma condição e a quantidade de execuções não precisa estar determinada diretamente na declaração do laço.

Como a condição é verificada antes da execução, o bloco do while pode não ser executado nenhuma vez caso a condição inicial já seja falsa.

Sintaxe básica


                while (condicao) {
                    // Instruções executadas enquanto a condição for verdadeira

                    // Atualização da variável utilizada na condição
                }

Exemplo


                let tentativa = 1;

                while (tentativa <= 3) {
                    console.log("Tentativa número " + tentativa);

                    tentativa++;
                }

A atualização da variável de controle é necessária para que a condição possa se tornar falsa. Sem essa atualização, o programa poderá entrar em uma repetição infinita.

Referência: MDN Web Docs — while

Atividade prática

Somatório de três números

Desenvolva uma aplicação que utilize a estrutura de repetição while para solicitar três números ao usuário por meio de prompt(). A cada repetição, o número informado deverá ser acrescentado ao somatório. Ao final, o programa deverá apresentar os três números digitados e o resultado total da soma.

Como os valores serão solicitados por caixas de diálogo prompt(), o formulário terá apenas o botão Enviar e não possuirá campos de entrada.

Como acompanhar a saída

A atividade apresentará os números informados e o somatório em uma caixa visual dentro da página. As mesmas informações também serão enviadas ao console real do navegador por meio de console.log().

No Google Chrome ou Microsoft Edge, pressione Ctrl + Shift + J para abrir diretamente o console. Também é possível pressionar F12 e selecionar a aba Console. No macOS, utilize Command + Option + J.

Consulte também as instruções do Chrome DevTools .
