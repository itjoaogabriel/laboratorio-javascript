Vetores em JavaScript

Um vetor permite armazenar vários valores relacionados em uma única estrutura. Em JavaScript, os vetores são representados pelo objeto Array.

Cada valor ocupa uma posição identificada por um índice. A primeira posição possui índice 0, a segunda possui índice 1 e assim sucessivamente.

Quando utilizar

Os vetores são indicados quando precisamos armazenar e processar uma sequência de valores relacionados, como notas, nomes, preços ou quantidades.

Uma estrutura de repetição pode percorrer as posições do vetor para armazenar, consultar, comparar ou filtrar seus valores.

Sintaxe básica


                let notas = [];

                notas[0] = 8.5;
                notas[1] = 7;
                notas[2] = 9;

                console.log(notas[0]);

Nesse exemplo, o vetor notas possui três valores. A instrução notas[0] acessa o valor armazenado na primeira posição.

Exemplo com repetição


                let notas = [8.5, 7, 9];

                for (let i = 0; i < 3; i++) {
                    console.log(notas[i]);
                }

O contador i representa o índice acessado em cada repetição: 0, 1 e 2.

Referência: MDN Web Docs — Array

Atividade prática

Notas iguais ou superiores a 7,5

Desenvolva uma aplicação que leia três notas informadas pelo usuário, armazene esses valores em um vetor e depois apresente um relatório contendo somente as notas iguais ou superiores a 7,5.

As três notas serão solicitadas por meio de prompt(). O formulário terá somente o botão Enviar e não possuirá campos de entrada.

Como acompanhar a saída

A atividade apresentará as notas informadas e o relatório final em uma caixa visual dentro da página. As mesmas informações também serão enviadas ao console real por meio de console.log().

No Google Chrome ou Microsoft Edge, pressione Ctrl + Shift + J para abrir diretamente o console. Também é possível pressionar F12 e selecionar a aba Console. No macOS, utilize Command + Option + J.

Consulte também as instruções do Chrome DevTools .
