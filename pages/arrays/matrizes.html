Matrizes em JavaScript

Uma matriz organiza valores em linhas e colunas. Em JavaScript, ela pode ser representada por um vetor que possui outros vetores em suas posições.

Para acessar um valor, utilizamos dois índices: o primeiro indica a linha e o segundo indica a coluna.

Quando utilizar

As matrizes são indicadas para representar informações organizadas em duas dimensões, como tabelas, mapas, grades, posições de um jogo ou conjuntos de valores divididos em linhas e colunas.

Sintaxe básica


                let matriz = [
                    [1, 2],
                    [3, 4]
                ];

                console.log(matriz[0][0]);
                console.log(matriz[1][0]);

A expressão matriz[0][0] acessa o valor 1. A expressão matriz[1][0] acessa o valor 3.

Preenchimento com repetições


                let matriz = [];

                for (let i = 0; i < 3; i++) {
                    matriz[i] = [];

                    for (let j = 0; j < 3; j++) {
                        matriz[i][j] = 0;
                    }
                }

O primeiro for controla as linhas e o segundo controla as colunas. Para cada linha, um novo vetor precisa ser criado antes de receber os valores das colunas.

Atividade prática

Multiplicação de uma matriz 3×3

Desenvolva uma aplicação que alimente uma matriz 3×3 com valores inteiros. Depois, solicite um número inteiro ao usuário e apresente o conteúdo da matriz com cada valor multiplicado pelo número informado.

Os nove valores da matriz e o número multiplicador serão solicitados por meio de prompt(). O formulário terá somente o botão Enviar.

Como acompanhar a saída

Cada valor informado será registrado no console real do navegador com sua linha e coluna. A matriz multiplicada será escrita diretamente na página executada dentro do iframe.

Nesta atividade será utilizado document.write() porque esse recurso faz parte do exercício original. Em aplicações modernas, ele não deve ser usado como forma geral de inserir conteúdo na página.

Como document.write() pode substituir o documento carregado, o formulário poderá desaparecer depois da exibição da matriz. Para executar novamente, clique outra vez em Executar página.

No Google Chrome ou Microsoft Edge, pressione Ctrl + Shift + J para abrir diretamente o console. Também é possível pressionar F12 e selecionar a aba Console. No macOS, utilize Command + Option + J.

Consulte a documentação da MDN sobre document.write() .
