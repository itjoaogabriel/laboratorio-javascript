# Laboratório JavaScript

Projeto acadêmico desenvolvido durante a graduação em Análise e Desenvolvimento de Sistemas no UniSENAI Joinville.

A proposta foi criar um site que reunisse atividades de lógica de programação para consulta e execução no navegador. Os conteúdos foram organizados por tema, com uma breve explicação, exemplo de sintaxe, enunciado e código da solução.

## Conteúdos

- Estruturas condicionais: `if...else` e `switch`;
- Estruturas de repetição: `for`, `while` e `do...while`;
- Vetores e matrizes.

## Como funciona

Em cada atividade, o código da solução fica disponível para leitura e pode ser executado pelo botão **Executar página**. O resultado é carregado dentro do próprio site por meio de um `iframe`.

## Tecnologias utilizadas

- HTML5 para a estrutura das páginas;
- CSS3 para o layout e a adaptação a telas menores;
- JavaScript para os algoritmos e a execução das atividades;
- Git e GitHub para o versionamento do projeto.

## Como executar

Não é necessário instalar dependências.

1. Clone o repositório:

   ```bash
   git clone https://github.com/itjoaogabriel/laboratorio-javascript.git
   ```

2. Abra o arquivo `index.html` no navegador.

## O que aprendi

Durante o desenvolvimento, pesquisei formas de organizar a navegação, estruturar as páginas, trabalhar a responsividade com CSS e executar os códigos dentro do site. Também pratiquei a revisão dos próprios arquivos, a remoção de redundâncias e o uso de commits e branches para registrar a evolução do projeto.
